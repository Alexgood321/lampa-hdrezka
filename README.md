# HDREZKA plugin для Lampa

Плагин для Lampa: просмотр HDRezka и чтение собственных коллекций избранного из аккаунта. Версия **1.3.2**.

## Возможности

- 🔴 **Отдельная кнопка «HDREZKA» рядом со «Смотреть» / «Онлайн»** на странице фильма. Кнопка встаёт первой и сразу получает фокус — просто нажмите **OK** и сразу откроется экран просмотра.
- 🔐 **Вход через временный диалог пароля**, пароль не сохраняется в `Lampa.Storage` и не показывается в настройках. Вход проверяется загрузкой `/favorites/`. Cookie принадлежат домену HDRezka и передаются браузером при наличии доступа.
- 🎬 **Балансер** в стандартной кнопке «Онлайн» — HDREZKA доступна и оттуда.
- 🎙 **Выбор озвучки (переводчика)** — все доступные переводы фильма попадают в фильтр «Перевод» в верхней части экрана.
- 📺 **Выбор качества** (360p / 480p / 720p / 1080p / 1080p Ultra / 4K) — передаётся в `Lampa.Player`, переключается прямо в плеере.
- 📅 **Сериалы**: сезоны и серии парсятся со страницы, с таким же выбором перевода.
- 📝 Субтитры (если есть в ответе HDREZKA) подхватываются и передаются в плеер.
- 🌐 **Настраиваемый домен**: по умолчанию `https://rezka.fi`, можно переключить на любое рабочее зеркало (`hdrezka.ag`, `rezka.ag` и т. д.).
- 🛰 Опциональная поддержка **CORS-прокси** на случай блокировок.
- ❤️ **Избранное HDRezka** в главном меню и настройках: коллекции, постеры, фильмы и сериалы, пагинация и точный переход к просмотру без поиска по названию.
- 🔎 **Карточка Lampa**: попытка сопоставить название и год с TMDB; при неоднозначном совпадении открывается поиск Lampa.

## Установка

1. Используйте постоянную ссылку на плагин с собственного Netlify:
   ```
   https://alexgood321-rezka-lampa.netlify.app/rezka.js
   ```
   Файл автоматически обновляется при успешном деплое ветки `main`. Для уже установленного плагина с адресом `cdn.jsdelivr.net/...@SHA/rezka.js` однократно замените ссылку на Netlify, иначе старая зафиксированная версия останется навсегда.
2. Откройте Lampa → **Настройки** → **Расширения** → **Добавить плагин**.
3. Вставьте URL, нажмите **Готово**, проверьте статус — должен быть `200`.
4. **Перезапустите** Lampa.

> ⚠️ Если ваша Lampa работает по `https://`, плагин и прокси тоже должны быть по `https://`. Иначе браузер (или Android WebView) заблокирует mixed-content.

## Подключение аккаунта HDREZKA

1. После установки в **Настройки** появится новая секция **HDREZKA**.
2. Заполните:
   - **Домен HDREZKA** — оставьте `https://rezka.fi` или укажите рабочее зеркало.
   - **Логин / E-mail** — логин или email от вашего аккаунта.
   - **Пароль** — вводится только после нажатия «Войти в аккаунт» и не сохраняется.
3. Нажмите **Войти в аккаунт** и введите пароль в открывшемся диалоге.
   - Описание этого пункта обновится:
     - 🟢 «Вы вошли в аккаунт» — подтверждён доступ к `/favorites/`;
     - 🔴 «Ошибка: …» — что-то пошло не так (неверный пароль, капча, CORS).
4. Откройте любой фильм — рядом со «Смотреть» / «Онлайн» будет зелёная кнопка **HDREZKA**, уже под фокусом. Нажмите **OK** — откроется экран выбора озвучки / сезона / серии.


## Netlify (без VPS)

Доступен **серверный шлюз на Netlify Functions + Blobs**, сохраняющий шифрованную сессию между запросами. Отдельный VPS, Docker и собственный домен не нужны. Плагин 1.3.1 совместим с этим API через существующее поле «Личный HTTPS-шлюз». Инструкция: [netlify/README.md](netlify/README.md). До подключения Netlify Site и проверки зеркала нельзя считать авторизацию рабочей.

## Личный HTTPS-шлюз для iPhone

Начиная с 1.3.0 поддерживается самостоятельный шлюз на Node.js 22. Он принимает запросы Lampa через HTTPS и обращается к выбранному зеркалу HDRezka, сохраняя сессию на сервере в памяти. В настройках HDREZKA появились «Личный HTTPS-шлюз», «Токен личного шлюза» и «Проверить личный шлюз».

**Установка и проверка:** см. [bridge/README.md](bridge/README.md). Без собственного работающего HTTPS-шлюза авторизация из Lampa на iOS может оставаться недоступной из-за CORS. Проверка с реальным аккаунтом пока не пройдена, поскольку зеркала могут использовать JavaScript-вход или Cloudflare.

**Ограничения безопасности:** токен хранится локально в Lampa и доступен другим установленным JS-плагинам. Не подключайте недоверенные расширения вместе с авторизованным шлюзом. Доступ через Lampa запрещён [правилами HDRezka](https://rezka.fi/rules/): возможна блокировка аккаунта.

## Избранное HDRezka

После входа откройте **«Избранное HDRezka»** в главном меню или через **Настройки → HDREZKA → Открыть избранное HDRezka**. Выберите коллекцию, фильм или сериал. Для каждого названия доступны **«Смотреть на HDRezka»** и **«Открыть карточку Lampa»**.

Коллекции загружаются из HDRezka при каждом открытии. Кнопка **«Проверить связь с HDRezka»** в настройках проверяет сеть/CORS без отправки пароля. Избранное **не импортируется автоматически в CUB/Trakt** и не меняет их закладки. Выход в настройках очищает локальные параметры, но не гарантирует завершения браузерной сессии на стороне HDRezka.

## Если не работает: CORS-прокси

HDRezka может заблокировать прямые запросы из Lampa из-за CORS, SameSite cookies или Cloudflare. Важно: обычный CORS-прокси сам по себе **не обеспечивает** передачу сессионных cookies. Для авторизации нужен доверенный прокси с корректной поддержкой сессий и `Set-Cookie`; на iOS возможности WebView могут отличаться от Android TV.

Варианты:

- Использовать **Lampa без https** (HTTP-сборка) — у неё CORS обычно отключён.
- Указать в настройках плагина **CORS-прокси**. Любой `lampac`-совместимый прокси работает:
  ```
  https://your-proxy.example.com/
  ```
  Плагин будет вызывать `https://your-proxy.example.com/https://rezka.fi/...`.

## Безопасность

- Пароль кратковременно попадает в локальное поле настроек, но очищается после попытки входа. Начиная с 1.3.0, сохранённый ранее пароль очищается при каждом запуске.
- Для входа используется `/ajax/login/` выбранного HTTPS-зеркала. Логин блокируется для HTTP-зеркал и HTTP-прокси.
- Если настроен CORS-прокси, через него проходят логин, пароль и запросы избранного: используйте только доверенный прокси с защищённым соединением.

## Что делать если домен `rezka.fi` не открывается

Откройте «Настройки → HDREZKA → Домен HDREZKA» и подставьте актуальное зеркало (см. список рабочих зеркал в Telegram-каналах HDREZKA, на сайте поддержки и т. п.).

## Известные ограничения

- **Premium-контент**: 4K и некоторые озвучки доступны только владельцам HDrezka Premium. Без премиум-подписки сервер вернёт «премиум-плейсхолдеры», и плагин уведомит об этом.
- **Капча Cloudflare**: если HDREZKA включит капчу для вашего IP, авторизация через API не сработает — войдите в браузере один раз, потом повторите попытку.
- **iOS Safari / WebView**: сторонние cookies могут блокироваться. Требуется проверка сессии на конкретном устройстве.
- **Без аккаунта**: собственное избранное недоступно, но онлайн-поиск остаётся в плагине.
- **Реальные проверки**: синтаксис проверен, но работа авторизации и отображения приватных коллекций на устройствах требует проверки с аккаунтом HDRezka.
